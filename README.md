# Roll a ball (Maze Edition)

Nessa interprettação do Roll a ball 3d, o jogador deve procurar os conjuntos de 12 moedas douradas espalhadas no labirinto perdido!

Para movimentar-se, o jogoador usa das setas do teclado (← (esquerda), ↑ (cima), → (direita) e ↓ (baixo))
